# Анализатор гармоничности шрифтов

Инструмент для автоматической оценки пригодности шрифтов для детской учебной литературы на основе геометрических признаков и машинного обучения.

## Описание

Скрипт извлекает геометрические характеристики из TTF-файлов (кривизну, длину дуг, точки перегиба и др.) и с помощью модели Random Forest определяет, подходит ли шрифт для использования в материалах для детей 6–9 лет.

## Быстрый старт

### 1. Установка зависимостей

  pip install -r requirements.txt

### 2. Подготовка шрифтов

Поместите TTF-файлы в папку fonts/

### 3. Запуск

python font_analyzer.py

## Ключевые выводы

1. **Средняя кривизна** оказалась наиболее информативным признаком — именно она сильнее всего отличает «детские» шрифты от декоративных.

2. **Исторические букварные шрифты** (Bukvarnaya, SchoolBook) модель классифицирует ошибочно, так как их геометрия ближе к декоративным, чем к современным гротескам.

3. **Количество точек перегиба** не вошло в ТОП-15 важных признаков — вопреки ожиданиям, этот параметр оказался менее значимым.

4. **Пограничные случаи** (Oswald со средним баллом 3,0) модель классифицирует неуверенно, что соответствует реальной неоднозначности экспертных оценок.

- Модель обучена на ограниченной выборке (18 шрифтов)
